# 广告投放分析平台 MVP 页面规格

## 1. 文档目的

本文件用于定义广告投放分析平台 MVP 的页面结构、模块职责、展示字段、交互路径和首期范围边界，作为后续 demo 实现的直接依据。

## 2. 页面设计原则

- 页面围绕运营/优化师的工作流展开：`整体效果 -> 异常指标 -> 异常原因`
- 所有页面默认使用统一指标口径，不在不同页面切换公式定义。
- 首期优先展示信息密度和诊断效率，不追求复杂交互和重视觉包装。
- 页面默认适配桌面端，移动端仅保证基础可读。

## 3. 信息架构总览

MVP 包含 3 个核心页面：

| 页面 | 页面名 | 目标 |
| --- | --- | --- |
| 页面 1 | 总览 | 快速判断账户整体健康度与异常指标 |
| 页面 2 | 分维诊断 | 定位异常来自人群、资源位还是创意 |
| 页面 3 | A/B 测试预留区 | 对比 Control / Test 表现，验证优化方向 |

## 4. 页面 1：总览

### 4.1 页面目标

- 帮助用户在最短时间内判断账户是否存在异常
- 提供日 / 周 / 月视角切换
- 展示周同比与月同比
- 为下钻进入分维诊断提供入口

### 4.2 页面结构

#### 模块 A：页面头部

展示内容：
- 页面标题
- 时间筛选器
- 时间视角切换：日 / 周 / 月
- 对比方式说明：周同比 / 月同比

回答的问题：
- 当前看的是哪个时间范围
- 当前指标以什么时间粒度展示

#### 模块 B：核心指标卡片区

默认展示：
- 曝光量
- 点击量
- 花费
- 点击率
- 点击均价
- 千次曝光成本
- 支付转化量
- 支付转化率
- 转化成本
- 支付金额
- 支付ROI

展示要求：
- 每个卡片展示当前值
- 展示相对对比期变化率
- 对异常下滑或异常上升指标添加标签

回答的问题：
- 账户整体表现是否健康
- 哪些指标最值得优先关注

#### 模块 C：趋势图区

默认内容：
- 花费趋势
- 支付转化量趋势
- 支付ROI 趋势

展示要求：
- 支持切换主指标
- 支持显示对比期趋势
- 异常阶段可用背景色或标记强调

回答的问题：
- 波动是单日噪声还是持续趋势
- 花费与经营结果是否同步变化

#### 模块 D：异常摘要区

默认内容：
- 结构化异常总结
- 最值得优先下钻的维度提示
- “查看分维诊断”入口

示例输出风格：
- `近一周账户花费增长主要来自新闻信息流扩量，但支付转化率低于账户均值，建议优先查看资源位与宽泛人群表现。`

回答的问题：
- 我现在先看哪里
- 异常更可能来自哪个方向

### 4.3 页面交互

- 切换时间视角后，卡片和趋势图同步更新
- 点击异常卡片后，默认带着当前指标进入分维诊断页
- 点击异常摘要中的建议维度，可直接跳转到分维诊断对应 tab

## 5. 页面 2：分维诊断

### 5.1 页面目标

- 支持用户按维度定位问题来源
- 让用户快速判断“谁在带量，谁在拖效”
- 为后续优化动作和 A/B 测试提供依据

### 5.2 页面结构

#### 模块 A：维度切换区

默认 tab：
- 人群
- 资源位
- 创意

回答的问题：
- 我当前从哪个角度看异常

#### 模块 B：分维表现表

每个维度至少展示：
- 维度值名称
- 花费
- 点击率
- 支付转化率
- 转化成本
- 支付ROI

交互要求：
- 默认按花费降序
- 支持切换按支付ROI、转化成本、支付转化量排序
- 支持选中某一行查看趋势详情

回答的问题：
- 哪些维度消耗最大
- 哪些维度效率最低
- 哪些维度值得优先处理

#### 模块 C：维度趋势详情

默认内容：
- 当前选中维度的花费趋势
- 当前选中维度的支付转化率趋势
- 当前选中维度的支付ROI 趋势

回答的问题：
- 这个问题是突然出现还是持续恶化
- 该维度是否是这轮异常的主要来源

#### 模块 D：诊断说明区

默认内容：
- 基于当前维度的结构化结论
- 对应的业务解读

示例输出风格：
- `宽泛人群在近一周承担了更多消耗，但支付转化率显著低于核心人群，说明扩量带来的新增点击质量下降。`

回答的问题：
- 为什么这个维度有问题
- 这个问题对整体表现造成了什么影响

### 5.3 页面交互

- 从总览页带参进入时，优先打开对应指标和建议维度
- 点击表格行后，下方趋势和诊断说明同步更新
- 支持返回总览页查看其他异常

## 6. 页面 3：A/B 测试预留区

### 6.1 页面目标

- 用于展示创意实验结果框架
- 证明平台不只支持发现问题，也支持验证优化方向
- 为后续完整实验系统预留页面结构

### 6.2 页面结构

#### 模块 A：实验概览

展示内容：
- 实验名称
- 实验目标
- 测试变量
- 实验状态

默认设定：
- 测试对象为创意
- Control 为 `creative_a`
- Test 为 `creative_test`

#### 模块 B：核心结果对比卡

展示内容：
- CTR
- 支付转化率
- 转化成本
- 支付ROI

展示要求：
- 同时显示 Control 与 Test
- 显示差值或提升幅度
- 对更优结果添加优胜标识

#### 模块 C：实验结论区

默认内容：
- 简短结论摘要
- 是否建议继续放量
- 当前结果解释边界

示例输出风格：
- `Test 创意在支付转化率和支付ROI 上优于 Control，说明新素材在点击质量筛选上更有效，可作为后续放量候选。`

### 6.3 页面交互

- 从分维诊断页创意维度可跳转至 A/B 测试区
- 支持切换查看不同时间段结果
- 首期不支持创建实验、编辑实验或自动分桶

## 7. 页面级状态定义

### 7.1 正常状态

- 页面展示完整卡片、图表和表格
- 各模块指标与筛选条件一致

### 7.2 空数据状态

- 当筛选结果无数据时，显示统一空状态文案
- 不展示误导性 0 值指标

### 7.3 指标异常状态

- 若分母为 0，则对应比率类指标显示 `--`
- 页面仍保留结构，不因局部指标缺失破坏布局

## 8. 页面字段映射

### 8.1 总览页字段映射

- 核心卡片来自账户级汇总数据
- 趋势区来自按时间聚合后的日 / 周 / 月数据
- 异常摘要来自规则化诊断逻辑，不依赖 AI

### 8.2 分维诊断页字段映射

- 表格来自按维度聚合后的结果
- 趋势详情来自“当前维度值 × 时间”的聚合数据
- 排序基于当前筛选后的聚合指标

### 8.3 A/B 测试区字段映射

- 实验概览来自测试规则定义
- Control / Test 指标来自创意维度聚合结果

## 9. 首期不做的页面能力

- 不做跨页面多条件高级筛选
- 不做自定义指标配置
- 不做导出报表
- 不做批量勾选和批量操作
- 不做实验创建流程
- 不做自动诊断推荐和自动预算建议

## 10. Demo 实现建议

- 总览页和分维诊断页放在同一前端项目内，以顶部导航切换
- 页面风格采用业务后台式信息布局，突出清晰度与可读性
- 图表数量控制在必要范围内，优先保证结论路径清楚
- 首期优先实现：
  - 指标卡片
  - 趋势图
  - 维度表格
  - 诊断说明
  - A/B 对比卡
